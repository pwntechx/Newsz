1.3 — FUNCTIONAL SUMMARY

The Janus geometry provides three distinct advantages over a single toroidal vessel:

1. Differential thrust navigation — No attitude thrusters required. Vector changes are achieved by adjusting the thrust balance between the two cores. The hull does not rotate to change direction.

2. Reconfigurable cargo volume — Pod spacing adjusts in seconds via field modulation. The same hardware that holds the pods also repositions them. No separate actuation system required.

3. Redundant habitat — Two independent toruses mean the convoy can lose one core entirely and still maintain crew survival, propulsion, and navigation. Each core is a self-contained vessel.

THE INVERSION — NO FRONT VS BACK
The Convoy is a neutral-state vessel. Forward and aft are defined by thrust direction, not hull orientation. Core A faces one way, Core B faces the other. Together they form a symmetric geometry that can accelerate, decelerate, or rotate by adjusting the balance between them. The cargo volume remains undisturbed during vector changes — the pods do not need to be reoriented.
NV-DIAMOND WITNESS LAYER
NV-diamonds embedded in the magnetic coupling coils and cargo pod interfaces provide real-time strain and position data. Each pod's distance from both toruses is measured independently — mutual inductance between coils changes with pod location. The diamond witnesses gap stability as a secondary verification, ensuring field modulation commands are executed correctly.
VERDICT: SEALED. The Janus geometry is coherent: two independent toruses, confronting magnetic fields, cargo suspended between. No structural connection required. No attitude thrusters required. Redundant habitat. The diamond witnesses the geometry.
