◈ Foundation

Why Individual Baseline, Not Population Average

Each patient's healthy cells carry individual spectral signatures. A population average R introduces variance that obscures individual drift. R must be established from the patient's own healthy cells of the same type — extracted from an unaffected tissue region before any intervention begins.

If no unaffected region is available, healthy cells from the same patient at an earlier timepoint are the next best source. Population average is the last resort, not the default. The baseline belongs to this patient.

◈ Falsifications

What Would Break This Protocol

F1

Does individual baseline R drift with patient age?

If R itself shifts over a patient's lifetime, a baseline established at age 40 may not be a valid reference at age 60. The baseline library becomes a moving target rather than a fixed anchor.

Test

Longitudinal NV readout of healthy cells from the same patient over 5-year intervals. If R shifts significantly: baseline must be re-established periodically. The baseline library is a living record, not a single capture.

F2

Does a reprogrammed cell maintain alignment when reintroduced into the inflammatory tissue environment that degraded it?

A cell aligned in isolation may drift rapidly on recontact with the same tissue conditions. The surrounding environment acts as an external driving frequency on the cell's ionic environment via paracrine signaling and metabolic stress.

Test

Reintroduce cleared cells into an organoid model of the degraded tissue environment. Monitor drift rate via NV readout. If cells de-align within 24h: the tissue environment itself must be addressed. The cell is not the only node that needs repair.

F3

Does spectral variance within healthy cells allow population-level baseline, or require single-cell calibration?

If variance within a population of healthy cells is larger than variance between healthy and methylated cells, R has no discriminating power. The Wien ratio produces noise, not signal.

Test

100 healthy cells vs 100 methylated cells of same type. Compute within-group vs between-group spectral variance. If between-group variance is not significantly larger: individual cell baseline calibration is required before any population-level R is valid.

F4

Does the three-consecutive-reading clearance gate correlate with long-term alignment maintenance?

The gate is a design choice that requires empirical validation. It may need to be tighter or looser depending on what F2 reveals about tissue re-exposure dynamics.

Test

Compare long-term outcomes for cells passing the three-reading gate versus cells passing single-reading criteria only. This calibrates the gate itself — the clearance threshold is not fixed, it is a parameter that learns from outcomes.
