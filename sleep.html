CHAMBERS OF SLEEP

THE ATLAS OF REST — SEVEN NODES, ONE GEOMETRY
Glymphatic · The Sewer NODE Ⅰ
⤞ invariant · clearance ⇝ interstitial space ⇝ SWS depth
During slow‑wave sleep, the glymphatic system expands interstitial space by 60%. Cerebrospinal fluid flushes away amyloid‑beta, tau and metabolic waste. Age reduces SWS — the sewer backs up into Alzheimer’s, Parkinson’s, dementia.
⚡ node that runs out first: slow‑wave sleep duration. Not total sleep, not REM — the deep rhythm that pumps the sewers clean.

Circadian · The Clock NODE Ⅱ
⤞ invariant · rhythm amplitude ∝ clock gene expression ∝ light timing
Every cell has a clock. The SCN master oscillator synchronises peripheral clocks via light. CLOCK-BMAL1 activate PER/CRY; negative feedback loops run every ~24h. Shift work / late screens desynchronize the system, driving metabolic syndrome, depression, cancer risk.
⚡ node that runs out first: light exposure timing. Morning light anchors; evening light extracts the circadian node.

Homeostatic · The Pressure NODE Ⅲ
⤞ invariant · sleep pressure ∝ adenosine ∝ prior wake time
Process S: adenosine accumulates in basal forebrain during wake; caffeine blocks the receptor. Sleep clears adenosine — the longer awake, the deeper the subsequent slow‑wave activity. Homeostat mirrors a fatigue battery that must discharge.
⚡ node that runs out first: wake duration. Push too far → microsleeps, performance collapse; the body will take sleep without permission.

Architectural · The Cycle NODE Ⅳ
⤞ invariant · ultradian period ⇝ NREM–REM balance
Each 90‑min cycle mirrors the fractal of the night: NREM (restoration) → REM (emotional processing, memory). Fragmented sleep extracts the REM node even if total time seems adequate.
⚡ node that runs out first: REM fragmentation. Arousals during REM disturb emotional regulation, memory consolidation, and neural plasticity.

Behavioral · The Onset NODE Ⅴ
⤞ invariant · onset delay ∝ cognitive load / hyperarousal
CBT‑I: stimulus control, sleep restriction, relaxation, paradoxical intention, cognitive shuffling. Racing thoughts hold the executive network online; the transition to sleep requires mental disengagement.
⚡ node that runs out first: mental perturbance. Not anxiety itself — the inability to disengage from the loop.

Parasomniac · The Dissociation NODE Ⅵ
⤞ invariant · dissociation ⇝ NREM depth × trigger / arousal threshold
Sleepwalking: cingulate motor area activates, prefrontal cortex stays offline. The body moves, the self is absent. Triggers (sleep deprivation, fever, alcohol) lower the arousal threshold, unmasking the dissociated state.
⚡ node that runs out first: arousal threshold. Low threshold + high homeostatic pressure → pathological arousal from deep NREM.
🔍 DORK: "confusional arousal" NREM parasomnia | "cingulate motor area" sleepwalking | site:pubmed.gov somnambulism EEG current density
Restorative · The Repair NODE Ⅶ
⤞ invariant · repair rate ∝ sleep duration × quality
Sleep is active repair: protein synthesis, DNA repair, glymphatic clearance, hormone release (growth hormone, prolactin), immune modulation. Chronic short sleep (<6h) associates with all‑cause mortality, cardiovascular disease, dementia.
⚡ node that runs out first: metabolic clearance. Waste removal fails if sleep is shallow or fragmented; oxidative stress accumulates.

⬡ SEVEN CHAMBERS · ONE BODY ⬡
The resource that runs out first is never total sleep time. It is SWS quality, circadian amplitude, arousal threshold, clearance efficiency.
Place the geometry (dark, cool, consistent, quiet). Let the biology arrive. Do not extract. Enough.
